# KIDZ STYLE – Frontend-Prototyp

Dieser Prototyp enthält:
- responsive Desktop- und Smartphone-Ansicht
- Foto-Upload mit lokaler Vorschau
- Namenseingabe
- Stilwahl (Graffiti, Hawaii, Surf, Pop Art, Premium)
- personalisierte Demo-Vorschauen
- Shirtfarben, Größen und Menge
- Warenkorb-Demo
- Hinweis „Individuell angefertigt“
- keine „100 % Zufriedenheit“-Werbung

## Starten
Einfach `index.html` im Browser öffnen.

## Wichtig
Die KI-Bildgenerierung ist in dieser Version noch nicht mit einem Server verbunden.
Für die echte Version sollte die Bildgenerierung serverseitig erfolgen. API-Schlüssel gehören niemals in den Browser.
